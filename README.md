# MindTrace

MindTrace is a local AI thinking-mapping app powered by the QVAC SDK.

It takes a messy thought, problem, or idea and transforms it into a structured visual map of:

- Goal
- Skills
- Constraints
- Blockers
- Opportunities

The AI inference runs locally through QVAC.

## Links

- GitHub Repository: https://github.com/dabeded12-boop/MindTrace
- Local App: http://localhost:3000

> Note: The local app URL works when MindTrace is running on your computer with `node server.js`.

## Requirements

- Node.js 18+
- npm
- QVAC SDK 0.19.0+
